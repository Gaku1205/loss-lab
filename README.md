# loss-lab

専門学生・大学生向けに、勾配降下・過学習・モデル設計・報酬設計をラボ風の4つのミニゲームで学ぶ無料のブラウザゲーム集

- 仕様：[docs/spec.md](docs/spec.md)
- 見た目：[docs/design.md](docs/design.md)

[ai-dev-template](https://github.com/Gaku1205/ai-dev-template) の工場で、1行のメモ（vercelでAIのディープラーニングや機械学習をゲームとして学びながら遊べるサイトを作って。対象は専門学生、大学生、社会人）から作ったサービスです。Issue を書くと、AI が清書・実装・レビュー・マージまで進めます（[docs/pipeline.md](docs/pipeline.md)）。
